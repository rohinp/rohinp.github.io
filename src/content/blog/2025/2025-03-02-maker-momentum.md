# Maker Momentum

I rebuilt this site to be opinionated: markdown in, transparent cards out. No CMS, no dashboards, just files and git.

Keeping entries organized by year/date lets me scan the repo history like a logbook. When inspiration hits, I create a new file, commit, and push.

### Ritual

1. Write in a plain editor.
2. Save under `src/content/blog/<year>/<date>-slug.md`.
3. Let the build pipeline do the rest.

It is boring on purpose—and that's why it works.
